02 / On your phone

Install Trove on Android

A direct, signed APK — no Play Store account needed. Takes about a minute.

  1. 01

    Download the APK

    Tap the button below. The file is 3.9 MB and works on Android 7.0 and newer.

    Download Trove v1.0
  2. 02

    Allow this source

    Android will ask for permission because the app is not from the Play Store. Open Settings when prompted and enable Allow from this source for your browser or Files app.

  3. 03

    Install and open

    Confirm the install, then launch Trove from your home screen. Play Protect may show a warning for sideloaded apps; only continue if the file came from this page.

Good to know

  • The Android app and the web app are the same product; your data stays on whichever device you use.
  • iPhone and desktop users can use the web app — no install required.
  • This build is served directly from this site. It is not yet on Google Play.
